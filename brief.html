Para uso avanzado

Generar el brief desde la terminal

pip install -r requirements.txt python market_brief.py --demo # sin red, datos de ejemplo python market_brief.py # datos reales (índices, resultados, noticias) python market_brief.py --json-out brief.json # guarda también el JSON
Rutina sugerida

Cómo usarlo cada mañana

01

Corre el script antes de la apertura

python market_brief.py con tu propia lista de índices y watchlist.

02

Revisa si hoy hay un evento macro de alto impacto

CPI, PCE, FOMC o el reporte de empleo suelen mover al mercado entero, no solo a un sector.

03

Cruza el calendario de resultados con tus posiciones

Un earnings en un ticker que tienes abierto es motivo para reducir tamaño o ajustar el stop antes del reporte.

04

Lee los titulares con escepticismo

Son un punto de partida para investigar, no una señal de compra/venta por sí solos.

Este brief automatiza la recolección de información pública (precios, calendario de resultados, titulares) — no analiza sentimiento, no pondera relevancia más allá del orden de publicación, y la sección de calendario macro es una referencia de frecuencia típica, no un calendario económico en vivo. No es asesoría financiera personalizada — antes de tomar decisiones de inversión o trading, considera consultar con un profesional certificado.
