Herramientas de línea de comandos

El screener RSI y la calculadora de hipoteca también corren desde la terminal, con datos reales o tus propios archivos.

Screener RSI (con datos reales de mercado o tus CSVs)
pip install -r requirements.txt python rsi_screener.py --tickers SPY QQQ AAPL MSFT --period 2y
Calculadora de hipoteca (exporta tabla de amortización)
python mortgage_payoff.py --principal 100000 --rate 6.5 --original-years 30 --target-years 5
Brief diario de mercado (índices, resultados, noticias)
python market_brief.py --json-out brief.json

Todas las herramientas de este repositorio usan modelos financieros simplificados con fines educativos y de planeación. Ninguna constituye asesoría financiera personalizada — antes de tomar decisiones de inversión, deuda o trading, considera consultar con un profesional certificado.
